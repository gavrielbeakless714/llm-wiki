# 📒 llm-wiki - Organize your personal knowledge base easily

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/gavrielbeakless714/llm-wiki/releases)

llm-wiki is a desktop application. It helps you store and organize your notes, research, and ideas. You manage all your information in one place on your computer. This software works like a private wiki. You create pages, link them together, and search through your data quickly.

## 🚀 Getting Started

You do not need programming skills to use this software. Follow these instructions to set up the application on your Windows computer.

1. Open your web browser.
2. Go to the [official release page](https://github.com/gavrielbeakless714/llm-wiki/releases) to download the latest setup file.
3. Find the file in your Downloads folder. It will have an .exe extension.
4. Double-click the file to start the installation process.
5. Follow the prompts on your screen to complete the setup.
6. Open the llm-wiki icon from your desktop or start menu.

## 💻 System Requirements

This application runs on most modern desktop environments. Ensure your computer meets these basic standards:

* Operating System: Windows 10 or Windows 11.
* Memory: 4 gigabytes of RAM or more.
* Storage: 200 megabytes of free space.
* Processor: Any dual-core processor from the last five years.

The software performs best with current updates installed. Check your Windows Update settings if you encounter stability issues.

## 📁 Managing Your Data

Your wiki stores data in a local folder. You choose where to save this folder during the first launch. This keeps your files under your control. You can back up your wiki by copying this folder to an external drive or a cloud storage service.

The interface shows a sidebar on the left. This area lists all your notes. Click any title to open the page. Use the search bar at the top to find specific terms across your entire database.

## ✍️ Creating Content

You write in the central editor. Use standard keyboard inputs to format text. The editor supports lists, headers, and links. To connect two pages, use double brackets around a name like this: [[Page Name]]. The application then maps the connection for you. This structure creates a network of information rather than a simple list of files.

Do not worry about saving your progress. The application autosaves every change you make to the text. Close the window when you finish your work. Your data remains safe in the chosen folder.

## ⚙️ Settings and Customization

Adjust the behavior of the application in the Settings menu.

* Theme: Switch between light mode and dark mode to suit your environment.
* Storage Location: Change the folder path if you want to store your wiki on a different drive.
* Font Size: Adjust the text scale for better readability.

## ❓ Frequently Asked Questions

**Is my data private?**
Yes. All files exist only on your local hard drive. No data travels to an external server. You own every character you type.

**Can I export my notes?**
Yes. The software saves all notes in standard text formats. You can open them in any word processor or text editor if you stop using this application.

**How do I update the software?**
When a new version releases, visit the [link](https://github.com/gavrielbeakless714/llm-wiki/releases) again. Download the new installer and run it. The installer replaces the old version while keeping your data folder intact.

**Does this application require an internet connection?**
No. You can write, edit, and organize your wiki while offline. An internet connection helps only when checking for newer releases.

## 🛠 Troubleshooting

If the application fails to open:
1. Verify the installation finished correctly.
2. Ensure no antivirus software blocked the execution of the file.
3. Restart your computer.
4. If problems persist, move the wiki folder to a different location on your hard drive, then set the new path in the software preferences.

If you cannot find a specific note:
1. Check the trash folder within the application settings if you deleted a page recently.
2. Use the search tool and verify you typed the correct name.
3. Check the file folder directly through Windows Explorer to ensure the file exists.

## 🛡 Security and Privacy

Your security remains a priority. This software does not track your behavior. It does not collect statistics about your notes. It communicates only with the update server to check for new version numbers. If you move your wiki folder to a shared cloud drive, ensure that service follows your personal security preferences.

Use the settings menu to lock the application if you share your computer with others. This adds a password requirement when you open the program. Keep this password in a secure place. You cannot recover the password if you lose it because the application does not store recovery information.
